# Analyti-Cult GTM Intelligence Hub

AI-first GTM intelligence prototype, isolated from the general Analyti-Cult application.

## Run

```bash
pip install -r gtm_intelligence_hub/requirements.txt
streamlit run gtm_intelligence_hub/app.py
```

The initial application is a synthetic-data prototype, not a validated prediction system. Live signal discovery, model training, connectors, and LLM inference are planned work.
